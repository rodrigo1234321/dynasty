Top 5 Correcciones Prioritarias

1. Archivos Técnicos Ausentes (robots.txt y sitemap.xml)

GoogleBot no dispone de un sitemap para rastrear las rutas del catálogo ni de un robots.txt para conocer las reglas de indexación.

Crear src/app/robots.ts y src/app/sitemap.ts con la estructura dinámica de rutas de Next.js.

2. Sin Datos Estructurados Schema.org (JSON-LD)

No se incluye Schema para la Organización ni para los Productos. Esto impide obtener Rich Snippets (precios, stock, marca) en los resultados de Google.

Agregar esquemas JSON-LD (Organization, LocalBusiness y Product) en layout.tsx y páginas de producto.

3. Title Tag Corto y Sin la Keyword Principal "Tecnología"

El título actual es "DYNASTY — Built Different" (23 caracteres). Es demasiado corto (se recomienda 50-60) y no optimiza para la búsqueda objetivo.

Modificar el título por: "DYNASTY — Tecnología & Setup Built Different | Mar del Plata"

4. Falta Tag Canónico (<link rel="canonical">)

Al estar desplegado en GitHub Pages con posibles parámetros de búsqueda (`?category=...`), se requiere una etiqueta canónica para evitar contenido duplicado.

Configurar en layout.tsx: alternates: { canonical: 'https://rodrigo1234321.github.io/dynasty/' }

5. Optimización de Imágenes a Formatos Modernos (WebP)

Las imágenes del catálogo están en formato PNG tradicional. Convertirlas o servirlas optimizadas mejorará el score de Core Web Vitals.

Servir imágenes comprimidas en WebP/AVIF.
